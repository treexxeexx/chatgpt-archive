# ChatGPT Archive

一个用于归档 ChatGPT 对话、分支和第一方附件的 Tampermonkey 用户脚本。

> **这是归档工具，不是云备份服务。** 归档文件保存在你自己的设备上，备份和隐私管理仍然由你自己负责。

## 安装

1. 安装 Tampermonkey 或其他兼容的用户脚本管理器。
2. 打开脚本的 Raw 地址：
   https://raw.githubusercontent.com/treexxeexx/chatgpt-archive/main/chatgpt-archive.user.js
3. 在用户脚本管理器中确认安装。
4. 打开或刷新 `https://chatgpt.com/`。

脚本同时匹配 `https://chat.openai.com/`。

## 基本使用

- 登录你自己的 ChatGPT 账号。
- 点击脚本添加的 ChatGPT Archive 按钮。
- 选择需要归档的对话。
- 按需选择是否下载可用的第一方附件。
- 第一次使用本地归档比较时，选择你保存 ChatGPT 归档的目录。
- 使用 **检查更新** 对比服务器上的对话和已有本地归档，找出需要下载或更新的内容。

## 使用注意事项

- **请只在你自己的 ChatGPT 账号上使用。**  
  脚本会使用浏览器当前已经登录的 ChatGPT 会话，不需要你手动填写 Token、Cookie 或 API Key。

- **脚本会读取你的对话内容。**  
  包括普通对话、归档对话、Project 中的对话，以及部分第一方附件。导出的内容可能包含非常私密的信息，请注意本地归档文件的存放位置。

- **当前版本不会把你的对话上传到第三方服务器。**  
  数据请求发生在当前 `chatgpt.com` / `chat.openai.com` 页面和 ChatGPT 自己的接口之间，导出的文件保存在你自己选择的位置。

- **第一次使用本地归档功能时，需要选择一个目录。**  
  建议单独创建一个专门用于 ChatGPT Archive 的文件夹，不要直接选择整个用户目录、桌面根目录之类范围过大的位置。

- **“检查更新”会读取已有归档结构。**  
  当前主要识别归档目录里的 `structure` 和 `structure_new` 数据，用来判断哪些对话已经下载、哪些需要更新。不要随意手动修改这些结构文件，否则可能影响判断结果。

- **大量下载时不要反复点击。**  
  ChatGPT 的接口有请求频率限制。脚本内部已经主动放慢部分请求并做了重试，但一次性归档很多对话或附件时仍然可能遇到 `429`、超时或临时错误。遇到这种情况，稍等一会再继续即可。

- **附件不保证 100% 都能下载。**  
  一些旧附件、临时文件、Code Interpreter 文件或已经失效的下载地址，可能无法再次获取。对话正文能导出，不代表其中所有历史附件一定还存在。

- **不要把导出的归档随便公开。**  
  导出文件里可能包含：
  - 对话正文
  - 邮箱或姓名
  - 上传文件名
  - Project 名称
  - 对话 ID
  - 代码、密钥或其他你曾经发给 ChatGPT 的内容

  如果要分享归档，最好先人工检查一遍。

- **ChatGPT 网页更新后，脚本可能暂时失效。**  
  这个脚本依赖 ChatGPT 当前的网页结构和内部接口。OpenAI 如果调整页面或接口，某些功能可能会需要跟着更新。

- **建议保留旧归档备份。**  
  如果你已经积累了很多本地归档，升级脚本前最好先复制一份。脚本虽然尽量避免破坏已有数据，但归档数据本身往往比脚本更重要。

- **Tampermonkey 自动更新依赖 GitHub Raw。**  
  当前脚本的 `@updateURL` 和 `@downloadURL` 都指向这个公开仓库。以后发布新版本后，Tampermonkey 可以从这里检查更新。

## 隐私说明

脚本运行在你的浏览器中，并使用当前已经登录的 ChatGPT 会话。它不会要求你把账号密码、Cookie、Token 或 API Key 粘贴进脚本。

由于导出的对话可能包含高度私密的信息，请把归档文件当作敏感的本地数据管理。分享任何归档前建议先检查内容，并把备份保存在你信任的位置。
